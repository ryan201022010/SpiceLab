    電路學基礎

    一、 電流與電動勢

    • 核心觀念：微觀導電模型 \(I = nAev_d\) 、電動勢 \(\varepsilon\) 與端電線 \(V = \varepsilon - Ir\) 區分非理想電池內部的化學推動力與內電阻壓降

    • 微觀動畫 (HTML5 Canvas/P5.js)：動態展示金屬導體內，自由電子在不加電壓時的隨機熱運動，以及加上電壓後 克服晶格碰撞產生的定向「漂移速率 \(v_{d}\) 」

    • 滑桿變數控制：讓使用者調整載流子密度 \(n\) 或截面積 \(A\) 動態觀察電流 \(I\) 的數據變化

    二、 電阻與歐姆定律

    • 核心觀念：歐姆定律的適用條件（線性元件 \(V=IR\) ）、電阻定律 \(R = \rho\frac{L}{A}\) ，以及電阻率與溫度的線性關係 \(R = R_0(1+\alpha \Delta T)\)

    • 幾何重塑視覺化：設計一個可拖曳拉長的導線 3D 或 2D 圖像，當使用者把導線「拉長」或「變細」時，圖像即時改變，並動態更新電阻值

    • 溫度效應圖表：加入溫度滑桿，即時在圖表上繪製出非歐姆導體（如鎢絲燈泡）與一般電阻的 \(V-I\) 特性曲線差異

    三、 電路分析與守恆定律

    • 核心觀念：克希荷夫第一定律（節點電流守恆，電荷守恆）與第二定律（迴路電位升降代數和為零，能量守恆） 基本的串聯分壓與並聯分流原理

    • 視覺化電位階梯圖：在複雜電路的下方，同步繪製出對應的「電位高度變化圖（高低起伏的階梯）」，幫助學生直觀理解「繞一圈電位代數和為零」的能量觀念

    • 節點流速指示：在電路節點處以小水流或粗細箭頭動態標示電流分配，驗證流入等於流出

    四、 電功率與能量

    • 核心觀念：克希荷夫第一定律（節點電流守恆，電荷守恆）與第二定律（迴路電位升降代數和為零，能量守恆） 基本的串聯分壓與並聯分流原理

    • 視覺化電位階梯圖：在複雜電路的下方，同步繪製出對應的「電位高度變化圖（高低起伏的階梯）」，幫助學生直觀理解「繞一圈電位代數和為零」的能量觀念

    • 節點流速指示：在電路節點處以小水流或粗細箭頭動態標示電流分配，驗證流入等於流出

    五、 複雜電路與儀表

    • 核心觀念：惠斯同電橋的平衡與測量、檢流計改裝成安培計（並聯小電阻分流）與伏特計（串聯大電阻倍壓）的電路原理

    • 電表改裝沙盒 (Sandbox)：提供一個基本的微安培計計頭，讓使用者自行「打字輸入」或「拖曳連接」分流/倍壓電阻 若輸入錯誤的阻值，虛擬電表會出現「指針爆表破表」或「燒毀」的警示動畫

    • 滑動變阻器測未知電阻：模擬惠斯同電橋實驗，使用者可拖曳滑塊直到檢流計讀數歸零，藉此練習推導公式

    六、 電容與 RC 電路暫態

    • 核心觀念：電容器的儲能原理 \(Q=CV\) 、 \(RC\) 電路充電與放電時，電荷、電壓、電流隨時間呈指數變化的暫態過程，以及時間常數 \(\tau = RC\) 的物理意義

    • 動態示波器 (Oscilloscope Simulation)：當使用者點擊「切換開關（充電/放電）」時，程式會以動態時序繪製出電壓（或電流）隨時間變化的漸進曲線 \(1-e^{-t/RC}\)

    • 快慢速暫態調整：調整電容 \(C\) 或電阻 \(R\) 的數值，使用者能立刻看到示波器上的波形變陡峭（充電變快）或變平緩（充電變慢）
